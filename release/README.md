# Photo Wall Android APK

`Photo-Wall-v1.0.0.apk` was built from source commit `32178d9` with Flutter
3.29.2 on 6 November 2026. It is a release-mode Android APK signed with the
project's debug key for assignment review.

SHA-256: `84C0D700F40E2067C0D24E97CCE46D65B46B1A863E7490FAD288C7CC9C640A0D`

Install it with `adb install -r Photo-Wall-v1.0.0.apk`. If Android reports a
signature conflict with an older Photo Wall installation, uninstall the older
app first; that removes its local cache and app data.

The APK installed and launched on an API 35 Android emulator. Scrolling to the
end of the gallery and opening the final photo worked in the release build.
The user will perform the remaining manual review before submission.
